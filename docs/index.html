How to use this manual

Read Documents 01 and 02 in your first week, in order. They cover the lab's context and the practical setup required to get started. Documents 03 through 06 can be read in any order and referred back to as needed.

Each document is standalone: you can link directly to any section using the URL and the anchor in the sidebar. The manual will be updated as the lab's tools and practices evolve.

If you have questions not addressed here, ask on Slack or bring them to your weekly 1:1.
